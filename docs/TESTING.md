## 標準プレビューの確認範囲

0.1.0では公式API、公式ソース、VS Code 1.105.1配布物から、仮想FS、変更イベント、`markdown.showLockedPreviewToSide` の登録とURIの扱いを確認した。0.1.1では同版の標準Markdown Previewカスタムエディター登録と公開コマンド `vscode.openWith` の引数を確認し、URIとエディター種別で既存タブを探すよう変更した。

0.1.0検証時に小規模プローブと統合テストを用意したが、画面付き起動ではXサーバー・ソケットを利用できず、headlessではGTKが表示接続を必要として停止した。**GUI統合テストは起動段階で阻害され、合格していない。** 0.1.1では既存タブの再利用・閉じて再表示の検証を統合テストへ追加し、構文検査を実施した。GUIでの実行結果はない。

次の確認はユーザー実機で行う:

- [MIGRATION_0.2.0.md](MIGRATION_0.2.0.md) に従って旧版を無効化し、新版を導入する。
- [ACCEPTANCE.md](ACCEPTANCE.md) の0.2.0移行確認M1〜M6、その後に残り16項目（入力形式、未保存編集、画像・リンク、Restricted Mode、異常系など）を0.2.0で確認する。

統合テストは表示可能な環境で `npm run test:integration` を実行する。`MPJST_VSCODE_VERSION` で対象バージョン、`MPJST_VSCODE_EXECUTABLE` で既存実行ファイルを指定できる。

0.1.0の自動テストはNode.js 24.19.0・VS Code内蔵Node.js 22.19.0で各17件成功だった。0.1.1は各22件（既存17件＋タブ再利用5件）。今回の0.2.0は識別子・状態分離の2件を追加し各24件。統合テストも新IDへ変更して構文確認したが、GUI実行はしていない。
