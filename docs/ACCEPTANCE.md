## 続けて確認する項目（16項目とも未実施）

| 項目 | 操作 | 期待結果 |
|---|---|---|
| 4拡張子 | `.yaml`, `.yml`, `.md`, `.txt` を新規作成しidentityを実行 | 同じテキストが変換へ渡り、元ファイルを変更しない |
| 未保存入力 | 自動保存が起きる前に編集して手動実行するか、試験文書で一時的にAuto Saveを切る | エディターにある未保存内容を使う。拡張は保存を行わない |
| 未保存JS | 試験JSを未保存で編集して実行 | 保存済み版で実行する旨の案内。未保存編集は未使用 |
| 複数処理 | identityサンプルを別名でも配置 | 両方が候補に出る。追加に再ビルド不要 |
| 候補なし | 新規の空 `transforms` を持つフォルダで選択実行 | 作成先を案内し、成功扱いにしない |
| キャンセル | 候補表示でEsc | 結果・前回の組を変えない |
| 初回失敗 | 新規試験ワークスペースで構文エラーのJSを選ぶ | 成功結果なし。空の成功プレビューを作らない |
| エラー保持 | 成功後、例外・不正な戻り値・構文エラーの試験JSを選ぶ | 以前の結果を維持し対象と原因を通知。前回再実行は以前成功した組 |
| 対象消失 | 成功後、試験入力または処理を別名に改名して再実行 | 消失を報告して前の結果を保持。復元後は再試行可能 |
| 無限ループ | 専用試験JSで `module.exports = () => { while (true) {} };` | VS Code操作が続けられ、初期設定10秒で終了。診断に時間切れ |
| 未完了Promise | 専用試験JSで `module.exports = () => new Promise(() => {});` | 中断ボタンまたは中断コマンドで終了し、再実行できる |
| 連打 | 長い処理の実行中に再実行を追加 | 実行中と案内され、二重起動しない |
| 未信頼 | 新規試験ワークスペースをRestricted Modeで開く | 変換実行を拒否する。信頼は内容確認の上で本人が変更 |
| 複数ルート | 別々のtransformsを持つ2ルートを開く | 入力と同じルートの候補だけ。再実行も元の組 |
| 画像・リンク | 入力と同じフォルダ以下に小さな画像・リンク先を置きidentityで表示 | 画像表示・読取リンクが動く。`../`画像とワークスペース外は対応保証外 |
| 状態保持 | 成功後に入力やJSを変更してからVS Codeを再起動 | 自動実行せず古い結果を再表示。手動再実行で新内容へ |
